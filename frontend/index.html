Limits

  • Scores are not calibrated. A high score is not a measured chance of cancer.
  • The image type detector cannot tell a breast scan from any other picture. Any image gets a score.
  • Public sample images may be part of the data the model was trained on, so a correct answer on them proves little.
  • Nothing is sent anywhere except the model service. History stays in this browser.
